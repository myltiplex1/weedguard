Compose one MCP tool named weed_plot(plot_id: str, plan_id: str = '', confirmation_code: str = '') that safely removes weeds from one maize plot in two calls. plan_id and confirmation_code are OPTIONAL parameters with default value '' (empty string): the first call passes only plot_id. Because the parameter types are written straight into the Python signature, set param_types exactly to: plot_id -> str, plan_id -> str = '', confirmation_code -> str = ''.
CALL 1 (only plot_id given): run capture_plot_image(plot_id); if it is not ok return status 'error' with stage 'camera', its error_code and its message. Run check_image_quality(image_path); if it is not ok return status 'blocked' with stage 'image_quality' and its problems list, and stop. Run detect_plants(image_path) and keep its preview_path. Run select_weed_targets(scan_id); it returns maize_count, weed_count, safe_target_count and skipped_near_maize. If safe_target_count is 0 return status 'nothing_to_do' with maize_count, weed_count, skipped_near_maize and a message that every weed is too close to maize. Otherwise run plan_weeding(selection_id); if it is not ok return status 'blocked' with its message. Then run request_operator_confirmation(plan_id) and return status 'awaiting_approval' with plot_id, plan_id, maize_found (maize_count), weeds_found (weed_count), weeds_safe_to_remove (safe_target_count), weeds_skipped_near_maize (skipped_near_maize), estimated_seconds (from plan_weeding), summary (from request_operator_confirmation), preview_image (the preview_path from detect_plants) and next_step. next_step must tell the agent to ask the farmer, and only if the farmer agrees, to call weed_plot again with plot_id, plan_id and the 4-digit confirmation_code the farmer reads from the robot operator console. The code is never in any result; never invent one.
CALL 2 (plan_id and confirmation_code both non-empty): run execute_weeding_plan(plan_id, confirmation_code) and return its result with status 'done' if ok, otherwise status 'not_done'. If confirmation_code is given without plan_id return status 'error'.
Rules: never call fire_laser; never remove anything in call 1; pass every error message from the functions through to the result so the agent can explain it to the farmer.
